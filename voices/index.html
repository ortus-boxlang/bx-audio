    Voices

    Every voice of the Piper collection: which can be used, which cannot, and why.

    On this page
    • Licenses
    • Available voices
    • Using voices in a product you sell
    • Not offered
    • Updating this list

    These are the voices audioSpeak() can use. They are Piper voices from the rhasspy/piper-voices collection, and none of them is bundled with the module: each is downloaded the first time you use it, into ~/.bxaudio/voices (see Storage).

    bx-audio voices                       # the voices you can use, from the command line
bx-audio voices --excluded            # the voices that are not offered, and why
bx-audio voices joe                   # one voice in detail
bx-audio install joe                  # download a voice ahead of time
bx-audio speak "Hello" --voice=joe     # or just use it, it installs itself

    audio = audioSpeak( text="Hello from BoxLang", voice="joe" );
audioSave( audio, "hello.mp3" );

    Licenses

    Voices whose model card states an open license are listed: CC0, public domain, CC BY, CC BY-SA, Apache 2.0 or the Unlicense. A few voices are listed with a check license warning because their card is unclear or non-commercial; they speak, but you decide whether they fit your use. The license column is the identifier we map the card's wording to, and the card itself stays the authority, so read it when it matters (the link in the last column leads to the training data). Other voices whose card says non-commercial, names a custom license, says only "See URL", or says nothing are not listed. The usage column says what the license means for a product you sell, see Using voices in a product you sell.

    Using voices in a product you sell

    Every offered license allows commercial use, except the voices marked check license, which are non-commercial or unclear and should stay out of a product you sell. Each voice has a usage:

    UsageLicensesWhat you do
    permissiveCC0, public domain, Unlicense, Apache 2.0Nothing is required. With Apache 2.0, keep the license notice.
    attributionCC BYCredit the creator of the training data and link the license. For model training, Creative Commons says the credit can be a link to the source of the dataset.
    sharealikeCC BY-SACredit as above. The license also asks that adapted material you share carries the same terms. Whether speech made by a model is adapted material is not settled, so read the card, and take advice if you need to be sure.

    audioCredits( [ "joe", "en_US-sam-medium" ] ) or bx-audio credits joe sam writes the credits for the voices you use, ready to paste into an about page. Filter the list with audioVoices( usage="permissive,attribution" ) or bx-audio voices --usage=permissive,attribution.

    These licenses were written for datasets and software, not for speech made by a model, so a few questions have no settled answer. This page is a guide, not legal advice. The code of this module is Apache 2.0, and the MP3 libraries are LGPL jars that you download separately.
