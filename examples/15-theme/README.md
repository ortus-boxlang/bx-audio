# The BxAudio theme

The anthem that plays on the home page: a grid anthem at 132 BPM in D minor (Dm, Bb, C, Am), with a filter that opens over the intro, an arpeggio, a harp run, a chime and a two bar hero motif answered by a second two bars that end higher. Everything is made from code, with no samples.

```bash
boxlang theme.bxs        # writes out/theme.wav next to the script
```

The chords, the motif and the scale are plain arrays near the top of `theme.bxs`, so change the notes and render again.
